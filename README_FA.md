# آیکون‌ولت (IconVault)

**[English](README.md) | فارسی**

مرورگر آیکون‌های کوچک و کاملاً آفلاین. جستجو ← مرور ← پیش‌نمایش ← شخصی‌سازی ← کپی/دانلود SVG از مجموعه‌های **Lucide**، **Tabler** و **Phosphor**. ساخته‌شده با React + TypeScript + Vite + Tailwind CSS v4. بدون بک‌اند، بدون API، بدون CDN — همه‌چیز به‌صورت محلی باندل شده است.

## امکانات

- **جستجو** در ۸٬۷۲۳ آیکون بر اساس نام و تگ‌ها — به فارسی یا انگلیسی (رتبه‌بندی: تطابق دقیق ← پیشوند ← شامل شدن ← تگ/کلیدواژه)
- **مرور بر اساس مجموعه** — سایدبار و چیپ‌های فیلتر با شمارش زنده
- **پنل پیش‌نمایش شیشه‌ای** — شخصی‌سازی زنده: اندازهٔ ۱۶ تا ۱۲۸ پیکسل، رنگ‌های آماده و انتخاب رنگ دلخواه، ضخامت خط ۰٫۵ تا ۳ (فقط Lucide/Tabler؛ برای Phosphor که توپر است مخفی می‌شود)
- **کپی SVG** (با بازخورد «کپی شد» و کپی سریع از روی کارت‌ها) و **دانلود SVG** — خروجی‌ها مستقل‌اند و اندازه/رنگ/ضخامت انتخابی شما را دارند
- **علاقه‌مندی‌ها** — در `localStorage` ذخیره می‌شود
- **پوستهٔ تیره/روشن** و **انگلیسی/فارسی** با پشتیبانی کامل راست‌به‌چپ — هر دو ذخیره می‌شوند و پیش از اولین رندر اعمال می‌شوند
- **دسترس‌پذیر** — جفت‌رنگ‌های بررسی‌شده با WCAG، حلقهٔ فوکوس قابل‌مشاهده، رفتار دیالوگ با قفل فوکوس، و پشتیبانی از `prefers-reduced-motion`

## سیستم طراحی «LED Lab»

پس‌زمینهٔ مشکی مات، رنگ تأکیدی لیمویی کم‌مصرف، و نور به‌عنوان «وضعیت»:

- درخشش توکنیزه شده است (`shadow-glow-sm/md/lg` و `drop-shadow-glow*`) با بودجهٔ سخت‌گیرانه: برند، آیتم فعال سایدبار، جستجوی فوکوس‌شده، دکمهٔ اصلی و هیروی پنل — چیز دیگری نمی‌درخشد
- آیکون‌ها هنگام هاور «روشن می‌شوند» (روشنایی ۸۰٪ ← ۱۰۰٪ همراه با هالهٔ هم‌شکل خود گلیف)
- **JetBrains Mono** فونت داده‌ها است (نام آیکون‌ها، شمارش‌ها، مقادیر)؛ Inter صدای رابط کاربری و Vazirmatn فونت فارسی است
- فقط یک سطح شیشه‌ای: پنل پیش‌نمایش (`backdrop-blur` + نور لبهٔ ماشینی)
- شبکهٔ نقطه‌ای تنها در پوستهٔ تیره؛ پوستهٔ روشن کاغذی گرم با لیمویی عمیق‌تر دارد
- راست‌به‌چپِ جهت‌آگاه: پنل و کشو سمتشان عوض می‌شود؛ همه‌جا از پراپرتی‌های منطقی CSS استفاده شده است

## راه‌اندازی

نیازمند Node ≥ 22.12 است.

```bash
npm install
npm run icons:build   # کپی SVGها و متادیتا از node_modules به public/icons (فقط یک بار)
npm run dev
```

## اسکریپت‌ها

| دستور | توضیح |
| --- | --- |
| `npm run dev` | اجرای سرور توسعه |
| `npm run icons:build [-- --force]` | بازسازی `public/icons/` از پکیج‌های موجود (اگر قبلاً ساخته شده باشد خودکار رد می‌شود) |
| `npm run build` | بررسی تایپ و بیلد پروداکشن |
| `npm run preview` | پیش‌نمایش بیلد پروداکشن |

پوشهٔ `public/icons/` تولیدشده و gitignore شده است — پس از کلون جدید یا به‌روزرسانی پکیج‌های آیکون، `icons:build` را اجرا کنید.

## ساختار پروژه

```
scripts/build-icons.mjs      پایپ‌لاین آیکون‌ها: node_modules ← public/icons (+ metadata.json)
public/icons/                SVGها و متادیتای تولیدشده (gitignore)
src/
  components/                Header، Sidebar، SearchBar، IconGrid، IconCard، IconPreview
  hooks/                     useIcons، useTheme، useLanguage، useFavorites
  utils/                     search (فیلتر رتبه‌دار)، svg (بارگذاری/ساخت/کپی/دانلود)
  data/                      icons (لودرهای کش‌شده)، collections (توصیف‌گرها)
  locales/                   en، fa
```

## نکات

- **کاملاً آفلاین** — فونت‌ها (Inter، JetBrains Mono، Vazirmatn) و همهٔ SVGها به‌صورت محلی باندل شده‌اند؛ برنامه هیچ درخواست خارجی نمی‌زند.
- **جستجوی دوزبانه** — کلیدواژه‌های فارسی در زمان بیلد از یک واژه‌نامهٔ انگلیسی→فارسی تولید می‌شوند (`scripts/fa-dictionary.json` با حدود ۵۴۰ واژهٔ پرکاربرد؛ پوشش حدود ۸۸٪ آیکون‌ها). برای افزودن واژه، آن را در واژه‌نامه بنویسید و `npm run icons:build -- --force` را اجرا کنید.
- ابتدا متادیتا بارگذاری می‌شود (مجموعاً حدود ۲ مگابایت با کلیدواژه‌های فارسی)؛ متن SVG هر آیکون به‌صورت درخواستی و کش‌شده دریافت می‌شود.
- گرید در دسته‌های ۱۵۰تایی با `IntersectionObserver` رندر می‌شود — با ۸٬۷۲۳ آیکون روان است و نیازی به virtualization نیست.
- کلیدهای ذخیره‌سازی: `iv:theme`، `iv:lang`، `iv:favorites`.
